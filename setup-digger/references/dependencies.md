# 依存ツールの確認と導入

選択された資料形式だけ確認する。コマンド名の存在だけでなく、実行・言語データ・モデル・短い入力での結果を確認する。バージョンや導入方法は実行時の公式手順とインストール済み版の `--help` を正とする。

共通の必須依存は、抜き書き照合用の Python 3.10以上。追加の Python パッケージは不要。合成の短い原文と、その原文に一致する `extracts.json` を一時ディレクトリへ置き、同梱 `report.py --check` の成功を確認する。不一致の引用では失敗することも確認し、環境記録に残す。

既存Pythonを使い、uvや仮想環境は新設しない。`markdown.py` の生成も同じサンプルで確認する。OpenAlexの引用探索とRSS/Atomの新着確認を選ぶ場合は、[補助スクリプトの実行条件](../../digger/references/helpers.md)も確認する。直接通信が環境規約で使えない場合は、同梱されていることだけで `ready` としない。

## 機能と確認項目

| 機能 | 優先して調べるもの | 動作確認 |
|---|---|---|
| Web | 実行環境の検索機能と本文を取得・保存できる機能。取得CLIは既存の `ax` | 公開の短い検索語で検索し、結果のページ本文を取得・保存。既定の文字数制限を解除でき、末尾まで取得できること |
| PDF | バイナリ取得機能、Poppler の `pdftotext`・`pdfinfo` | 既知の短いPDFから文字とページ境界を抽出し、原ページと照合 |
| OCR | ページ画像化用の `pdftoppm`、Tesseract 等と対象言語データ | 対象言語の既知の短文を含む画像PDFを読み、期待した文字と照合。日本語の縦書きを使う場合は別に確認 |
| 動画字幕 | `yt-dlp` 等。必要なランタイムもその版の公式要件で確認 | 字幕付きの短い公開動画から、選択言語の字幕を動画本体なしで取得し、時刻と本文を確認 |
| 音声認識 | 既存のローカル実装または選択サービス。必要なら FFmpeg、モデル、認証参照 | 既知の短い音声を原言語で文字起こしし、語句と時刻を確認 |

公式情報の入口：

- ax: https://github.com/yusukebe/ax
- Poppler: https://poppler.freedesktop.org/
- Tesseract と言語データ: https://tesseract-ocr.github.io/tessdoc/Installation.html
- yt-dlp と依存関係: https://github.com/yt-dlp/yt-dlp#dependencies
- FFmpeg: https://ffmpeg.org/download.html
- ローカル音声認識を新しく選ぶ場合の候補: https://github.com/ggml-org/whisper.cpp

## 導入の手順

1. 対象コマンドを `command -v` とバージョン表示で確認し、解決先を記録する。mise 管理のランタイムは `mise exec --` 経由で確認・実行する。接続ツールは実際に利用できるかを確認する。
2. OCR は `tesseract --list-langs` 等で言語データを調べる。実行ファイルがあっても日本語がなければ日本語OCRは不足とする。音声認識もモデルの実体・対応言語・実行方法を確認する。
3. 不足分だけ公式情報で導入方法を調べる。例えば macOS で Homebrew を使っているなら対応する formula と追加データを確認し、mise 管理の既存ツールを別の管理方式で重複導入しない。導入先・コマンド・モデルの容量を具体化する。
4. ユーザーが確認した内容を導入する。インストール済みという理由で一括更新や再インストールをしない。サービスの秘密は設定に書かず、ユーザーが利用する認証管理方法に従う。
5. 一時ディレクトリで上表の機能確認を行う。公開サンプルまたは合成資料を使い、私的な Vault 資料を試験のために外部送信しない。料金の発生する検証も選択した送信・費用の範囲内で行う。
6. 確認できた引数・出力形式・言語・モデル・結果を環境記録へ書く。文字起こしでは翻訳になっていないことも確認する。試験で作った一時ファイルだけ片付ける。

`ax` はページ取得であり検索機能の代わりにはならない。検索手段がない環境はその不足を記録し、指定URLの取得だけで一般的な探索が可能になったと報告しない。

ネットワークや公開サンプルの都合で確認できない機能は `unverified` として理由を残す。設定を変えずに後日その機能だけ再確認できるよう、試した方法を記録する。
